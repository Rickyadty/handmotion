# Jemari (mediapipe-handmotion)

A simple demo of **Google MediaPipe Gesture Recognizer** built with React.

This project shows the basic on integrating MediaPipe.

## Getting Started

Install dependencies:

```bash
npm install
```
or
```bash
bun install
```

Start the development server:

```bash
npm run dev
```
or
```bash
bun run dev
```

Then open your browser and allow camera access.
The homepage features a fully interactive, working hand-detection demo. 
Check `/demo` to see a simplified integration example.

## Tech Stack

* React
* TypeScript
* [Google MediaPipe Tasks Vision](https://developers.google.com/edge/mediapipe/solutions/guide)
